# T4M2 Project – Flora Nomenclature Wizard

Projeto web desenvolvido com foco em nomeclatura de flora, utilizando tecnologias modernas e ambiente de desenvolvimento eficiente.

## 🚀 Tecnologias

Este projeto utiliza as seguintes tecnologias:

- [Vite](https://vitejs.dev/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)

## ✅ Requisitos

- Node.js instalado (recomenda-se a versão mais recente LTS): [Download Node.js](https://nodejs.org)
